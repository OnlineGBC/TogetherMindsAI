# Project Instructions

## Instruction Precedence
Instructions in this CLAUDE.md file and in memory (persistent across conversations) take precedence over Claude's default behavior. Always follow them exactly, even when they conflict with built-in defaults.

## Bug Fix Testing Policy
Every bug fix must be accompanied by at least one test that would have caught the bug or verifies the fix. Add the test in the same commit as the fix. This applies to all bug fixes, no exceptions.
